## Context

9 specs exist in `openspec/specs/`. Need to track implementation status for each.

## How it works

- The `tasks.md` file contains one section per spec
- Each requirement from the spec is a checkbox
- `[x]` = requirement implemented in code
- `[ ]` = requirement not yet implemented
- Overall progress shown by `openspec status` / `openspec instructions apply`

## Updating

When work on a spec is completed, check off the relevant requirement boxes in `tasks.md`.

How It Works

Write your pipeline in a single pipeline.tf file using the HCL language. Define repos, tasks with triggers and dependencies, and execution scripts — all in one place.

Kestrix resolves the DAG on every push, determines which tasks to run, and dispatches them to your GitLab Runner or local shell.

  • Declarative HCL syntax — no YAML spaghetti
  • Boolean trigger expressions with AND/OR/NOT
  • Automatic stage ordering from task dependencies
  • Manual gates for production deployments
  • CI generator produces .gitlab-ci.yml automatically

About Kestrix

Kestrix is an open-source CI/CD control plane built for teams that manage complex multi-repository systems. It was born from the frustration of maintaining dozens of .gitlab-ci.yml files across microservices, each with duplicated logic and inconsistent patterns.

Instead of configuring CI per-repo, Kestrix lets you define your entire pipeline in a single place — then resolves, triggers, and monitors execution across all your repositories.
